# Aturan untuk AI Agent

1. Pembuatan aplikasi harus selalu berdasarkan pada panduan di file `prd.md`.
2. Selalu referensi/cek ke `context7` untuk mengetahui praktik terbaik (best practice) serta konfigurasi terbaru terkait framework dan library yang digunakan dalam proyek ini.
3. Selalu gunakan *outline icon* (misalnya dari library SVG khusus seperti Lucide, Heroicons, atau lainnya), dan DILARANG menggunakan emoji standar sebagai ikon seperti: 🐺, 💊, 🔍.
4. Selalu utamakan pendekatan *Mobile-First* (Mobile friendly) dalam mendesain dan menyusun *layout* halaman. Pastikan antarmuka terlihat sempurna dan fungsional di layar HP sebelum disesuaikan untuk layar yang lebih besar.
